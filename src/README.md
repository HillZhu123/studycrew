# StudyCrew — 你的 AI 学习数字团队（5-Agent）

StudyCrew 是一个面向 IGCSE/A-Level 的“多 Agent 学习团队”前端 demo：5 个角色轮流输出备考计划、知识速记、模拟题、错题诊断与家长周报。

## 为什么需要 AI 团队，而不是单一 AI？
单一聊天模型往往擅长“解释”，但不擅长把学习流程拆成可执行动作：计划、讲解、训练、复盘、情绪支持需要不同视角协作。

## 解决方案：5 个 Agent 的分工逻辑
- PlannerAgent：把目标落到 72 小时时间块
- TutorAgent：提炼核心概念与方法
- DrillAgent：生成可练习的题与答案
- CriticAgent：定位典型错因并给补救
- CoachAgent：提供节奏与心理支持，输出周报摘要

## Tech Stack
- 纯静态 HTML + Tailwind CDN
- Vanilla JavaScript
- JSON 预置数据驱动（无后端）
